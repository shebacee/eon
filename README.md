# 📚 EON - Book Trading & Study Collaboration Platform

A comprehensive full-stack web application that combines book trading, collaborative study features, and community engagement through blog-style "thoughtwaves". Built as an academic project to demonstrate end-to-end web development capabilities.

## ✨ Features

### 📖 Book Trading
- Buy, sell, and trade books within the community
- Browse available books with detailed listings
- Secure transaction management

### 👥 Collaborative Study
- Create and join study groups
- Share study materials and resources
- Coordinate study sessions with peers

### 📝 Thoughtwaves (Blog)
- Share insights, reviews, and educational content
- Engage with community posts
- Build a knowledge-sharing ecosystem

### 🎯 Community-Driven MCQ System
- Users contribute questions and answers
- Dynamic quiz generation from community question bank
- Interactive learning and self-assessment tools

### 🤖 AI Chatbot Integration
- Intelligent assistant for platform navigation
- Personalized recommendations
- User support and guidance

### 🛡️ Admin Panel
- Content moderation and oversight
- User management
- Platform analytics and monitoring

## 🛠️ Tech Stack

**Frontend:**
- HTML5
- CSS3
- JavaScript

**Backend:**
- Python
- MySQL Database

**Development Tools:**
- PyCharm IDE
- Git version control

## 💡 Usage

### For Students:
1. **Register/Login** to create your account
2. **Browse Books** available for trading
3. **Join Study Groups** or create your own
4. **Contribute MCQs** to build the community question bank
5. **Take Quizzes** generated from user contributions
6. **Share Thoughtwaves** to engage with the community

### For Admins:
1. Access admin panel with admin credentials
2. Monitor user activity and content
3. Moderate posts and manage reported content
4. View platform analytics

## 🔒 Security Features

- User authentication and authorization
- Password hashing and encryption
- SQL injection prevention
- XSS protection
- CSRF tokens for form submissions
